1. Nonlinear optimal control problem (discrete time)

We start with a discrete-time nonlinear system
xk+1=f(xk,uk),k=0,…,N−1,x_{k+1} = f(x_k, u_k), \qquad k = 0,\dots,N-1,xk+1​=f(xk​,uk​),k=0,…,N−1,

and a finite-horizon cost

J=h(xN)+∑k=0N−1ℓ(xk,uk).\mathcal{J} = h(x_N) + \sum_{k=0}^{N-1} \ell(x_k, u_k).J=h(xN​)+k=0∑N−1​ℓ(xk​,uk​).

Goal:
Find a control sequence u0,…,uN−1u_0,\dots,u_{N-1}u0​,…,uN−1​ that minimizes J\mathcal{J}J subject to the dynamics.

SLQ/iLQR solves this iteratively by locally approximating the problem as LQ and using dynamic programming (Bellman).

2. Nominal trajectory and deviation variables

At iteration iii, we have a nominal trajectory
{xkn,ukn}k=0N−1,x0n given.\{x_k^n, u_k^n\}_{k=0}^{N-1}, \qquad x_0^n \text{ given}.{xkn​,ukn​}k=0N−1​,x0n​ given.

We work in deviation coordinates around this trajectory:
δxk:=xk−xkn,δuk:=uk−ukn.\delta x_k := x_k - x_k^n, \qquad \delta u_k := u_k - u_k^n.δxk​:=xk​−xkn​,δuk​:=uk​−ukn​.

We will compute increments δuk\delta u_kδuk​ (and thus update uknew=ukn+δuku_k^{\text{new}} = u_k^n + \delta u_kuknew​=ukn​+δuk​) to reduce the cost.

3. Linearization of the dynamics

Linearize the nonlinear dynamics around (xkn,ukn)(x_k^n, u_k^n)(xkn​,ukn​):
f(xk,uk)≈f(xkn,ukn)+Ak(xk−xkn)+Bk(uk−ukn),f(x_k, u_k) \approx f(x_k^n, u_k^n) + A_k (x_k - x_k^n) + B_k (u_k - u_k^n),f(xk​,uk​)≈f(xkn​,ukn​)+Ak​(xk​−xkn​)+Bk​(uk​−ukn​),

with Jacobians
Ak:=∂f∂x∣(xkn,ukn),Bk:=∂f∂u∣(xkn,ukn).A_k := \left.\frac{\partial f}{\partial x}\right|_{(x_k^n, u_k^n)}, \qquad B_k := \left.\frac{\partial f}{\partial u}\right|_{(x_k^n, u_k^n)}.Ak​:=∂x∂f​​(xkn​,ukn​)​,Bk​:=∂u∂f​​(xkn​,ukn​)​.

Because the nominal satisfies
xk+1n=f(xkn,ukn),x_{k+1}^n = f(x_k^n, u_k^n),xk+1n​=f(xkn​,ukn​),

the constant term cancels, and we obtain the linearized deviation dynamics

δxk+1=Akδxk+Bkδuk.\boxed{ \delta x_{k+1} = A_k \delta x_k + B_k \delta u_k. }δxk+1​=Ak​δxk​+Bk​δuk​.​

This is a linear time-varying (LTV) system.

4. Quadratic expansion of the cost

4.1 Stage cost expansion

Second-order Taylor expansion of the stage cost ℓ(xk,uk)\ell(x_k,u_k)ℓ(xk​,uk​) at (xkn,ukn)(x_k^n,u_k^n)(xkn​,ukn​):
ℓ(xk,uk)≈ℓkn+ℓx,k⊤δxk+ℓu,k⊤δuk+12 δxk⊤Lxx,k δxk+δxk⊤Lxu,k δuk+12 δuk⊤Luu,k δuk.\begin{aligned} \ell(x_k,u_k) &\approx \ell_k^n + \ell_{x,k}^\top \delta x_k + \ell_{u,k}^\top \delta u_k \\ &\quad + \tfrac12\,\delta x_k^\top L_{xx,k}\,\delta x_k + \delta x_k^\top L_{xu,k}\,\delta u_k + \tfrac12\,\delta u_k^\top L_{uu,k}\,\delta u_k. \end{aligned}ℓ(xk​,uk​)​≈ℓkn​+ℓx,k⊤​δxk​+ℓu,k⊤​δuk​+21​δxk⊤​Lxx,k​δxk​+δxk⊤​Lxu,k​δuk​+21​δuk⊤​Luu,k​δuk​.​

SLQ (as used in the paper) uses a Gauss–Newton style approximation and typically:

  • for common tracking costs there is no explicit xxx-uuu cross term, so Lxu,k=0L_{xu,k}=0Lxu,k​=0 exactly, or
  • simply drops Lxu,kL_{xu,k}Lxu,k​ to keep the structure LQR-like.

So we approximate
Lxu,k≈0,L_{xu,k} \approx 0,Lxu,k​≈0,

giving
ℓ(xk,uk)≈ℓkn+ℓx,k⊤δxk+ℓu,k⊤δuk+12 δxk⊤Lxx,k δxk+12 δuk⊤Luu,k δuk.\ell(x_k,u_k) \approx \ell_k^n + \ell_{x,k}^\top \delta x_k + \ell_{u,k}^\top \delta u_k + \tfrac12\,\delta x_k^\top L_{xx,k}\,\delta x_k + \tfrac12\,\delta u_k^\top L_{uu,k}\,\delta u_k.ℓ(xk​,uk​)≈ℓkn​+ℓx,k⊤​δxk​+ℓu,k⊤​δuk​+21​δxk⊤​Lxx,k​δxk​+21​δuk⊤​Luu,k​δuk​.

Define the LQ coefficients:
Qk:=Lxx,k,Rk:=Luu,k,qk:=ℓx,k,rk:=ℓu,k.Q_k := L_{xx,k},\quad R_k := L_{uu,k},\quad q_k := \ell_{x,k},\quad r_k := \ell_{u,k}.Qk​:=Lxx,k​,Rk​:=Luu,k​,qk​:=ℓx,k​,rk​:=ℓu,k​.

ℓ(xk,uk)≈ℓkn+qk⊤δxk+rk⊤δuk+12 δxk⊤Qkδxk+12 δuk⊤Rkδuk.\boxed{ \ell(x_k,u_k) \approx \ell_k^n + q_k^\top \delta x_k + r_k^\top \delta u_k + \tfrac12\,\delta x_k^\top Q_k \delta x_k + \tfrac12\,\delta u_k^\top R_k \delta u_k. }ℓ(xk​,uk​)≈ℓkn​+qk⊤​δxk​+rk⊤​δuk​+21​δxk⊤​Qk​δxk​+21​δuk⊤​Rk​δuk​.​

Similarly, expand the terminal cost h(xN)h(x_N)h(xN​) at xNnx_N^nxNn​:

5. Value function and Bellman equation

5.1 Original value function

For the discrete-time problem, the value function at time kkk is
Vk(x):=min⁡uk,…,uN−1[h(xN)+∑i=kN−1ℓ(xi,ui)],V_k(x) := \min_{u_k,\dots,u_{N-1}} \left[ h(x_N) + \sum_{i=k}^{N-1} \ell(x_i,u_i) \right],Vk​(x):=uk​,…,uN−1​min​[h(xN​)+i=k∑N−1​ℓ(xi​,ui​)],
subject to the dynamics starting from xk=xx_k = xxk​=x.

The value function tells:

If at time 𝑘𝑘k I am in state xxx, what is the minimum possible future cost I can achieve, assuming I act optimally from now on?”

The Bellman equation (principle of optimality) is
Vk(x)=min⁡u[ ℓ(x,u)+Vk+1(f(x,u)) ].V_k(x) = \min_{u} \big[\,\ell(x,u) + V_{k+1}(f(x,u))\,\big].Vk​(x)=umin​[ℓ(x,u)+Vk+1​(f(x,u))].
At the final time NNN:
VN(x)=h(x).V_N(x) = h(x).VN​(x)=h(x).

This principle of optimality is crucial:

Whatever the optimal strategy from now to the end is, its first action plus the optimal strategy afterwards must jointly be optimal.
Mathematically, this is encoded in the Bellman equation.

5.2 Local quadratic approximation of the value function

We approximate VkV_kVk​ locally around the nominal state xknx_k^nxkn​.

where we define

7. Principle of optimality: minimize the quadratic in δuk\delta u_kδuk​

By the Bellman equation,
Vk(δxk)=min⁡δukQk(δxk,δuk).V_k(\delta x_k) = \min_{\delta u_k} \mathcal{Q}_k(\delta x_k,\delta u_k).Vk​(δxk​)=δuk​min​Qk​(δxk​,δuk​).

We have a quadratic function in δuk\delta u_kδuk​:
Qk(δxk,δuk)=12 δuk⊤Hkδuk+δuk⊤(Gkδxk+gk)+(terms independent of δuk).\mathcal{Q}_k(\delta x_k,\delta u_k) = \tfrac12\,\delta u_k^\top H_k\delta u_k + \delta u_k^\top (G_k\delta x_k + g_k) + (\text{terms independent of }\delta u_k).Qk​(δxk​,δuk​)=21​δuk⊤​Hk​δuk​+δuk⊤​(Gk​δxk​+gk​)+(terms independent of δuk​).

The principle of optimality says:

The optimal control at time kkk minimizes the cost-to-go from that point onward.

So we set the gradient w.r.t. δuk\delta u_kδuk​ to zero:
∂Qk∂δuk=Hkδuk+Gkδxk+gk=0.\frac{\partial \mathcal{Q}_k}{\partial \delta u_k} = H_k\delta u_k + G_k\delta x_k + g_k = 0.∂δuk​∂Qk​​=Hk​δuk​+Gk​δxk​+gk​=0.

Solve for δuk\delta u_kδuk​:
δuk⋆=lk+Kkδxk,Kk:=−Hk−1Gk,lk:=−Hk−1gk.\boxed{ \delta u_k^\star = l_k + K_k \delta x_k, \quad K_k := -H_k^{-1}G_k, \quad l_k := -H_k^{-1}g_k. }δuk⋆​=lk​+Kk​δxk​,Kk​:=−Hk−1​Gk​,lk​:=−Hk−1​gk​.​

  • lkl_klk​ is the feedforward increment (appears because we have nonzero gradients rkr_krk​ and pk+1p_{k+1}pk+1​, i.e., tracking/nonzero nominal).

This is the optimal affine control law for the local LQ subproblem at time kkk.

9. Forward rollout and line search (one SLQ iteration)

One SLQ (iLQR) iteration consists of:

  1. Forward rollout (nonlinear)
    Given current control law (nominal) uknu_k^nukn​, simulate the nonlinear dynamics
    xk+1n=f(xkn,ukn)x_{k+1}^n = f(x_k^n, u_k^n)xk+1n​=f(xkn​,ukn​)
    from the current initial state to get the nominal trajectory {xkn,ukn}\{x_k^n, u_k^n\}{xkn​,ukn​}.

  2. Backward pass (LQ subproblem)

    • Linearize dynamics: Ak,BkA_k,B_kAk​,Bk​.
    • Quadratize cost: Qk,Rk,qk,rkQ_k,R_k,q_k,r_kQk​,Rk​,qk​,rk​.
    • Run the Riccati-like backward recursion to compute Kk,lkK_k, l_kKk​,lk​.

  3. Policy update via line search
    Using the affine law δuk=lk+Kkδxk\delta u_k = l_k + K_k\delta x_kδuk​=lk​+Kk​δxk​, define a new control sequence:
    uknew=ukn+α lk,u_k^{\text{new}} = u_k^n + \alpha\, l_k,uknew​=ukn​+αlk​,
    (and keep the feedback KkK_kKk​ for deviations during rollout), with step size α∈(0,1]\alpha \in (0,1]α∈(0,1].

    Roll out the nonlinear dynamics with this updated control law, compute the new cost Jnew\mathcal{J}_{\text{new}}Jnew​, and use a line search on α\alphaα until the cost decreases sufficiently.

  4. Set {xkn,ukn}\{x_k^n, u_k^n\}{xkn​,ukn​} to the new trajectory and repeat until convergence (or max iterations).

At convergence you obtain a locally optimal time-varying affine feedback policy:
uk(xk)=ukn+lk+Kk(xk−xkn).u_k(x_k) = u_k^n + l_k + K_k(x_k - x_k^n).uk​(xk​)=ukn​+lk​+Kk​(xk​−xkn​).

This is iLQR/SLQ as a solver for the single-shot finite-horizon nonlinear OCP.

10. SLQ-MPC: using iLQR in a receding-horizon loop

SLQ-MPC wraps the SLQ solver inside an MPC loop:

  1. At real time ttt, measure the current state x(t)x(t)x(t).
    Set it as the initial state x0nx_0^nx0n​ for the SLQ problem.

  2. Define a horizon of NNN steps (or time TTT) and a cost
    J=(x~N)⊤Hx~N+∑k=0N−1[x~k⊤Q x~k+u~k⊤R u~k+W(xk,k)],\mathcal{J} = (\tilde{x}_N)^\top H \tilde{x}_N + \sum_{k=0}^{N-1} \big[ \tilde{x}_k^\top Q\,\tilde{x}_k + \tilde{u}_k^\top R\,\tilde{u}_k + W(x_k,k) \big],J=(x~N​)⊤Hx~N​+k=0∑N−1​[x~k⊤​Qx~k​+u~k⊤​Ru~k​+W(xk​,k)],
    where x~k=xk−xkref\tilde{x}_k = x_k - x_k^{\text{ref}}x~k​=xk​−xkref​, u~k=uk−ukref\tilde{u}_k = u_k - u_k^{\text{ref}}u~k​=uk​−ukref​, and WWW may include waypoint penalties.

  3. Initialize the control law:

    • Use an LQR/PD law or the solution from the previous MPC step as the initial {ukn}\{u_k^n\}{ukn​}.

  4. Run a few SLQ iterations:

    • Forward rollout, linearization, quadratization.
    • Backward pass using Bellman (Riccati recursion, optimal affine increments δuk\delta u_kδuk​).
    • Line search update of uknu_k^nukn​.

  5. Apply only the first control:
    uapplied(t)=u0⋆u_{\text{applied}}(t) = u_0^{\star}uapplied​(t)=u0⋆​
    (possibly plus feedback K0(x(t)−x0n)K_0(x(t)-x_0^n)K0​(x(t)−x0n​)).

  6. Shift the horizon and repeat at the next time step:

    • New state measurement x(t+Δt)x(t+\Delta t)x(t+Δt).
    • Use previous solution shifted in time as a warm start for {xkn,ukn}\{x_k^n,u_k^n\}{xkn​,ukn​}.
    • Run SLQ again (usually only a few iterations needed if warm-started).

Additionally, as in the paper, you can:

  • Use an infinite-horizon LQR around the goal state to compute a terminal cost matrix H=P∞H = P_{\infty}H=P∞​, which serves as a good terminal cost for SLQ.
  • This approximates the cost-to-go beyond the MPC horizon and improves stability.

Thus:

  • Inside each MPC step: SLQ/iLQR uses Bellman’s principle and local quadratic approximations to compute a locally optimal affine law over the finite horizon.
  • Across time: MPC uses the first control of that law, moves the horizon, and recomputes, leading to an online receding-horizon nonlinear controller.

🔽 Appendix A: Line search and the role of feedback in SLQ/iLQR

You already have the local optimal incremental law from the backward pass:
δuk⋆=lk+Kk δxk,δxk=xk−xkn.\delta u_k^\star = l_k + K_k\,\delta x_k, \qquad \delta x_k = x_k - x_k^n.δuk⋆​=lk​+Kk​δxk​,δxk​=xk​−xkn​.

This is the solution of the local LQ subproblem (linearized dynamics + quadratized cost). Now we need to use it to update the nominal control sequence and generate a new trajectory on the true nonlinear system.

There are two closely-related notions here:

  1. Feedback vs feedforward
  2. Line search in the feedforward direction α\alphaα

A.1 Where does the feedback term go?

At iteration iii, you have:

  • Nominal trajectory: {xkn,ukn}\{x_k^n, u_k^n\}{xkn​,ukn​}
  • New increments: δuk⋆=lk+Kk δxk\delta u_k^\star = l_k + K_k\,\delta x_kδuk⋆​=lk​+Kk​δxk​

When you roll out the new candidate trajectory on the nonlinear system, you don’t know in advance what the new state xkx_kxk​ will be (because the dynamics are nonlinear). So you use the policy during the forward simulation:

  1. Start from the actual initial state:
    x0cand=x0current.x_0^{\text{cand}} = x_0^{\text{current}}.x0cand​=x0current​.

  2. At each time step kkk of the rollout:

    • Compute the state deviation:
      δxk=xkcand−xkn.\delta x_k = x_k^{\text{cand}} - x_k^n.δxk​=xkcand​−xkn​.
    • Compute the control increment using the affine law:
      δuk=lk+Kk δxk.\delta u_k = l_k + K_k\,\delta x_k.δuk​=lk​+Kk​δxk​.
    • Update the control:
      ukcand=ukn+δuk.u_k^{\text{cand}} = u_k^n + \delta u_k.ukcand​=ukn​+δuk​.
    • Apply ukcandu_k^{\text{cand}}ukcand​ to the nonlinear dynamics and get
      xk+1cand=f(xkcand,ukcand).x_{k+1}^{\text{cand}} = f\big(x_k^{\text{cand}}, u_k^{\text{cand}}\big).xk+1cand​=f(xkcand​,ukcand​).

So in full, with no line search, the candidate control during rollout is:
ukcand=ukn+lk+Kk(xkcand−xkn).u_k^{\text{cand}} = u_k^n + l_k + K_k \big(x_k^{\text{cand}} - x_k^n\big).ukcand​=ukn​+lk​+Kk​(xkcand​−xkn​).

🔹 The feedback term Kk(xkcand−xkn)K_k(x_k^{\text{cand}} - x_k^n)Kk​(xkcand​−xkn​) is always present in the forward rollout.
🔹 The SLQ backward pass gives you both lkl_klk​ and KkK_kKk​; you use the full law during rollout.

When we later introduce the step size α\alphaα, we only scale the feedforward part lkl_klk​, not the feedback:

ukcand(α)=ukn+α lk+Kk(xkcand(α)−xkn).u_k^{\text{cand}}(\alpha) = u_k^n + \alpha\, l_k + K_k\big(x_k^{\text{cand}}(\alpha) - x_k^n\big).ukcand​(α)=ukn​+αlk​+Kk​(xkcand​(α)−xkn​).

  • KkK_kKk​ stays unchanged (it’s the local stabilizing feedback for the LQ subproblem).
  • α\alphaα scales the step size in the direction of the feedforward increment lkl_klk​.

A.2 What is α\alphaα and what is “line search”?

After the backward pass, you have a search direction in control space, given by the sequence {lk}k=0N−1\{l_k\}_{k=0}^{N-1}{lk​}k=0N−1​:

  • Think of all uku_kuk​ stacked into a big vector uuu,
  • All lkl_klk​ stacked into a big vector lll,
  • Then the new control candidate is
    ucand(α)=un+α l(plus feedback corrections in rollout).u^{\text{cand}}(\alpha) = u^n + \alpha\,l \quad(\text{plus feedback corrections in rollout}).ucand(α)=un+αl(plus feedback corrections in rollout).

This is exactly the idea of line search in optimization:

We move along a direction lll from our current point unu^nun, and we choose how far to move by tuning the scalar step size α>0\alpha > 0α>0.

Concretely:

  1. You start with α=1\alpha = 1α=1 (a “full” step).
  2. You perform a forward rollout using
    ukcand(α)=ukn+α lk+Kk(xkcand(α)−xkn).u_k^{\text{cand}}(\alpha) = u_k^n + \alpha\, l_k + K_k\big(x_k^{\text{cand}}(\alpha) - x_k^n\big).ukcand​(α)=ukn​+αlk​+Kk​(xkcand​(α)−xkn​).
  3. You compute the new cost J(α)\mathcal{J}(\alpha)J(α) by summing the stage and terminal costs along the candidate trajectory.
  4. If J(α)<Jold\mathcal{J}(\alpha) < \mathcal{J}_{\text{old}}J(α)<Jold​ with sufficient decrease, accept this α\alphaα.
  5. If not, reduce α\alphaα (e.g. α←βα\alpha \leftarrow \beta \alphaα←βα with β∈(0,1)\beta \in (0,1)β∈(0,1), such as β=0.5\beta=0.5β=0.5) and try again.

This is called a backtracking line search. Formally:

  • We are minimizing the scalar function
    ϕ(α):=J(un+α l)\phi(\alpha) := \mathcal{J}\big(u^n + \alpha\,l\big)ϕ(α):=J(un+αl)
    (with feedback and dynamics included in how we evaluate J\mathcal{J}J).
  • We want an α\alphaα that gives actual decrease in cost for the true nonlinear problem, not just the local quadratic approximation.

A.3 Why not always α=1\alpha = 1α=1?

Intuitively:

  • The backward pass (Riccati step) gives an optimal step for the quadratic approximation of the cost and linearized dynamics.
  • But the true problem is nonlinear; the quadratic approximation may be poor if we step too far from the nominal trajectory.
  • A full step α=1\alpha = 1α=1 can overshoot: the new rollout might increase the cost or even destabilize the system.

So:

  • If the model is very nonlinear or the initial guess is far from optimal, α=1\alpha = 1α=1 may be too aggressive.
  • A smaller α\alphaα takes a shorter step, staying closer to the region where the local linear/quadratic approximation is valid.

In optimization language:

The Riccati backward pass gives you a descent direction lll.
The line search on α\alphaα ensures you get a descent step for the true cost.

In practice, people often try a sequence like:
α∈{1, 0.5, 0.25, 0.1, 0.05,… }\alpha \in \{1,\, 0.5,\, 0.25,\, 0.1,\, 0.05,\dots\}α∈{1,0.5,0.25,0.1,0.05,…}
and pick the largest α\alphaα that produces a sufficient cost decrease.

A.4 Why only scale lkl_klk​ and not KkK_kKk​?

  • KkK_kKk​ is chosen to be the optimal feedback for the local LQ approximation. It stabilizes deviations around the nominal and shapes how the state trajectory responds to disturbances during the rollout.
  • lkl_klk​ is the feedforward step that shifts the nominal control in the direction of lower cost.

Scaling both lkl_klk​ and KkK_kKk​ would break the carefully derived LQ structure. The standard (and widely used) iLQR/SLQ practice is:

  • Keep KkK_kKk​ as is (full feedback),
  • Scale only lkl_klk​ by α\alphaα.

So the update is:

  • Incremental law from backward pass:
    δuk⋆=lk+Kk δxk.\delta u_k^\star = l_k + K_k\,\delta x_k.δuk⋆​=lk​+Kk​δxk​.
  • Line search candidate during rollout:
    ukcand(α)=ukn+α lk+Kk(xkcand(α)−xkn).u_k^{\text{cand}}(\alpha) = u_k^n + \alpha\, l_k + K_k\big(x_k^{\text{cand}}(\alpha) - x_k^n\big).ukcand​(α)=ukn​+αlk​+Kk​(xkcand​(α)−xkn​).

A.5 Summary

  • The feedback term Kk(xk−xkn)K_k(x_k - x_k^n)Kk​(xk​−xkn​) is always used during the forward rollout to stabilize and correct the trajectory. It is not scaled by α\alphaα.
  • The feedforward term lkl_klk​ is the “direction” in control space given by the local LQ solution; we scale it by a step size α\alphaα.
  • Line search = choose α\alphaα by trying α=1,0.5,0.25,…\alpha=1,0.5,0.25,\dotsα=1,0.5,0.25,… and picking the largest one that actually reduces the true cost J\mathcal{J}J when the nonlinear system is rolled out.
  • This is how SLQ/iLQR combines:
    • a local quadratic optimization step (backward pass)
    • with a global cost check on the true nonlinear problem (line search),
      ensuring stable, monotonic convergence in practice.

    measures “How far am I from waypoint nnn’s state?”, but is weighted in time by the Gaussian, so it matters only near kp,nk_{p,n}kp,n​.

In other words:

  • x~k\tilde{x}_kx~k​ pulls the trajectory toward the global reference over the whole horizon.
  • x^n,k\hat{x}_{n,k}x^n,k​ adds extra pull toward specific waypoint states at specific times.

Tuning:

  • Larger Wp,nW_{p,n}Wp,n​ →\rightarrow→ waypoint nnn is more important in state space.
  • Larger ρp,n\rho_{p,n}ρp,n​ →\rightarrow→ narrower time window (more precise timing around kp,nk_{p,n}kp,n​).
  • Smaller ρp,n\rho_{p,n}ρp,n​ →\rightarrow→ looser requirement on when the waypoint is reached.

Potential concern (double-counting the same objective):

If the reference trajectory xkrefx_k^{\text{ref}}xkref​ already passes through the waypoints at the desired times (i.e. xkp,nref≈xnwpx_{k_{p,n}}^{\text{ref}} \approx x_n^{\text{wp}}xkp,n​ref​≈xnwp​), then near kp,nk_{p,n}kp,n​ the two errors
x~k=xk−xkref,x^n,k=xk−xnwp\tilde{x}_k = x_k - x_k^{\text{ref}}, \qquad \hat{x}_{n,k} = x_k - x_n^{\text{wp}}x~k​=xk​−xkref​,x^n,k​=xk​−xnwp​
are almost the same. In that case, the trajectory cost x~k⊤Qx~k\tilde{x}_k^\top Q \tilde{x}_kx~k⊤​Qx~k​ and the waypoint cost x^n,k⊤Wp,nx^n,k\hat{x}_{n,k}^\top W_{p,n}\hat{x}_{n,k}x^n,k⊤​Wp,n​x^n,k​ both pull toward essentially the same target, and their weights effectively add up.

If QQQ and Wp,nW_{p,n}Wp,n​ (and the temporal sharpness ρp,n\rho_{p,n}ρp,n​) are chosen too large simultaneously, the combined tracking + waypoint penalties can become dominant over other important terms (e.g. input regularization, obstacle costs, soft constraints). In practice, this means you must carefully tune:

  • the magnitude of QQQ vs. Wp,nW_{p,n}Wp,n​, and
  • how sharply in time the waypoint penalty is activated via ρp,n\rho_{p,n}ρp,n​,

to avoid over-emphasizing waypoints relative to the rest of the cost and to reflect the true task priorities.

C.3 Why this form is useful

  1. Soft waypoint constraints

    Instead of hard constraints xkp,n=xnwpx_{k_{p,n}} = x_n^{\text{wp}}xkp,n​​=xnwp​, they use a cost term.
    This lets the optimizer:

    • strongly encourage passing near the waypoint,
    • but still violate it slightly if dynamics or input limits require it.

  2. Quadratic in state →\rightarrow→ SLQ-friendly

    For each fixed kkk, W(xk,k)W(x_k,k)W(xk​,k) is quadratic in x^n,k\hat{x}_{n,k}x^n,k​.
    The time-dependent Gaussian is just a scalar weight, so the cost remains:

    • quadratic in state,
    • smooth in the time index.
      This fits perfectly into SLQ’s linear–quadratic approximation framework.

  3. Unifies trajectory tracking and waypoint shaping

    • The usual Q,R,HQ,R,HQ,R,H terms handle final/trajectory tracking via x~k,u~k\tilde{x}_k,\tilde{u}_kx~k​,u~k​.
    • W(xk,k)W(x_k,k)W(xk​,k) adds intermediate landmarks (gates, windows, obstacle clearances, etc.).
      Both are handled uniformly as running/terminal quadratic costs.

  4. Flexible tuning

    Different waypoints can have different Wp,nW_{p,n}Wp,n​ and ρp,n\rho_{p,n}ρp,n​, allowing:

    • emphasis on certain state components at specific waypoints,
    • precise timing for some waypoints and relaxed timing for others.

The waypoint cost W(xk,k)W(x_k,k)W(xk​,k) is a time-localized quadratic penalty that softly pulls the trajectory toward specified intermediate states at specified time steps, while preserving the quadratic structure needed by SLQ. It enforces waypoints “as soft constraints” without making the problem hard or infeasible.
